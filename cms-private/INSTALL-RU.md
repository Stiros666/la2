# LA2PLUS — GHTWEB 5 + дизайн + Lucera

Это установочный комплект на базе предоставленного GHTWEB 5.1.3. В комплект входят тема LA2PLUS, штатный кабинет GHTWEB, адаптеры Lucera2/Lucera3_it, установщик и зависимости PHP. Исходные файлы дизайна и оригинальный архив CMS сохранены отдельно в рабочей папке.

## Проверенное окружение

- PHP **8.3.33**, Yii **1.1.32**, MariaDB **11.4.8**.
- Расширения: pdo_mysql, mbstring, gd, openssl, curl, fileinfo, json, dom. Для Composer также zip.
- Apache с mod_rewrite или Nginx + PHP-FPM. Нужны HTTPS, возможность выбрать корень сайта и запускать PHP CLI через SSH/терминал панели.
- `memory_limit=256M`, `max_execution_time=120` для установки; после установки достаточно 30–60 секунд. Веб-процесс должен иметь исходящий доступ к игровым БД и SMTP.
- Корень домена — **папка `public`**, например `/var/www/la2plus/public`. Не публикуйте весь каталог CMS: в `protected` находятся настройки БД и журналы.

Конфиги веб-сервера: `deploy/nginx.conf.example`, `deploy/apache.conf.example`. Их необходимо адаптировать под домен, путь и сокет PHP-FPM. Конфигурации предоставлены как примеры; локальные проверки выполнялись встроенным сервером PHP, не Apache/Nginx.

## Установка с нуля

1. Распакуйте комплект в отдельную папку хостинга. Направьте домен в её `public`. Подключите HTTPS.
2. Создайте **отдельную пустую БД сайта** и отдельного пользователя. Не устанавливайте таблицы CMS в БД игрового сервера. На этапе установки нужны CREATE, ALTER, INDEX, SELECT, INSERT, UPDATE, DELETE и права для миграций. После установки ограничьте права по используемым функциям.
3. Дайте PHP-процессу запись в `protected/runtime`, `public/assets`, `public/uploads`. На время установки также нужны права записи в `protected/config` и `protected/config/database.php`. Используйте владельца/группу, а не общедоступный режим 777.
4. Из корня CMS выполните:

   ```sh
   php deploy/check.php
   php deploy/prepare.php
   ```

5. Откройте на своём HTTPS-домене путь из `protected/config/setup-url.txt`. Это секретная одноразовая ссылка установщика. Без неё установка закрыта. Если CLI выполнялся другим пользователем, обеспечьте PHP-процессу чтение `install-key.php`; не открывайте этот файл всем пользователям сервера.
6. Пройдите проверку каталогов, укажите БД сайта, запустите миграции, создайте администратора. Автоматически импортируются 20 164 записи каталога предметов. Дождитесь завершения миграций без ошибок.
7. Завершите установку. Появится `protected/config/lock`; ключ и ссылка установщика удаляются. Войдите в `/backend/` с созданными учётными данными.
8. Закройте PHP-процессу запись в `protected/config`. Сохраните `lock`. Не переносите в продакшен тестовые базы, кэш или учётные записи локального стенда.

В архиве нет готового администратора, паролей игрового сервера и установленной БД. Composer на хостинге не обязателен: `vendor` включён. Для воспроизводимой установки зависимостей используйте `composer install --no-dev` по включённому `composer.lock`.

## Подключение Lucera

1. В админке откройте **Логин-серверы**, создайте запись. Укажите IP и игровой порт loginserver, отдельно адрес/порт MySQL, имя БД, пользователя и пароль.
2. Выберите адаптер по **реальной структуре БД**, а не только названию сборки:
   - `Lucera2`: в исходном адаптере указано «Version >= 8.3»; используется `characters.charId`, `accounts.accessLevel`, `character_data`.
   - `Lucera3_it`: старый адаптер использует `characters.obj_Id` и другую структуру полей.
3. Тип пароля loginserver должен совпадать с настройкой сборки. GHTWEB поддерживает SHA1/Base64 и Whirlpool/Base64. SHA1/Base64 проверен на локальной тестовой схеме; тип для вашей ревизии не определён.
4. В **Игровые серверы** добавьте gameserver, привяжите созданный loginserver, укажите адрес игрового порта и отдельно доступ к игровой БД. Выберите соответствующий адаптер, включите сервер. Накрутка онлайна в новом виджете не применяется.
5. Разрешите доступ к MySQL игрового сервера только от IP веб-хостинга или через закрытую сеть. Для регистрации нужны SELECT/INSERT/UPDATE в `accounts`; расширенные услуги требуют дополнительных прав на соответствующие таблицы.
6. Выполните проверку, заменив `1` на ID gameserver:

   ```sh
   php deploy/check-lucera.php 1
   ```

   Проверка выполняет SELECT без получения записей для запросов accounts, characters, clans, items. Она не меняет игровые данные. Ошибки записываются в `protected/runtime/application.log`.
7. На копии реальной БД проверьте регистрацию, вход в игровой клиент, список персонажей, смену/восстановление пароля. Затем проверьте выдачу одного тестового предмета персонажу вне игры и его появление после входа.

**Совместимость с вашей конкретной ревизией Lucera, статистика замков/кланов и выдача предметов пока не подтверждены.** Для окончательной проверки нужны ревизия, структура игровых таблиц без данных игроков и тестовый сервер. Адаптер нельзя считать проверенным для всех современных сборок Lucera только по совпадению имени.

## Что заполнить перед открытием

- В админке: название/описание, новости, страницы, SMTP и адрес отправителя, игровые серверы, CAPTCHA и настройки регистрации.
- В `public/design/js/config.js`: дата открытия, рейты, ссылки на клиент/патч и официальные соцсети. Дата **25 сентября 2026** и рейты взяты из исходного дизайна; это не утверждённые настройки игрового сервера.
- Страницы `/page/downloads/`, `/page/rules/`, `/page/terms/`, `/page/privacy/`, `/page/community/` созданы с честными сообщениями об отсутствии опубликованного содержимого. Опубликуйте свои файлы, контакты и документы. Сейчас ссылок на реальные клиент/патч нет.
- В `themes/la2plus/views/layouts/landing.php` находится главная; страницы кабинета и формы — в `themes/la2plus/views/`; оформление — `public/design/css/cms.css` и `style.css`. Языковые переключатели относятся к главной странице; кабинет сохранён на русском.
- Включите SMTP и проверьте доставку на свой реальный адрес. Локально отправка проверялась только на тестовый SMTP-приёмник. Восстановление пароля использует штатный процесс GHTWEB: письмо со ссылкой, затем письмо с новым паролем.
- В магазине создайте категории, наборы и предметы. Для доната выберите платёжного провайдера, настройте секреты/подпись callback, валюту и курс. Платёжные модули GHTWEB сохранены, **актуальная совместимость конкретного провайдера и реальные платежи не проверялись**. Не включайте приём денег до проверки подписи, повторного callback и фактической выдачи на тестовом сервере.

## Обслуживание

- PHP errors: `protected/runtime/application.log` и журнал PHP-FPM.
- Отладка выключена по умолчанию. Не включайте `APP_DEBUG=1` на публичном домене.
- Миграции больше не запускаются на каждом посещении. После обновления сделайте резервную копию и выполните `php deploy/migrate.php`.
- Резервируйте БД сайта, `protected/config/database.php` и `public/uploads`. Сохраняйте резервные копии вне `public`.
- Исправления совместимости и отдельных ошибок не заменяют полный аудит всех унаследованных модулей GHTWEB 2019 года. Особенно это относится к платёжным интеграциям и операциям с игровыми предметами.

## Выполненные проверки

- Повторная установка на чистую MariaDB: миграции, каталог предметов, создание администратора, установка блокировки.
- PHP lint: 436 файлов приложения/тем без синтаксических ошибок (плюс проверка CLI-файлов отдельно).
- Главная, регистрация, вход, восстановление пароля, статистика без подключённого gameserver.
- Регистрация игрового аккаунта, проверка записанного SHA1/Base64, вход и открытие кабинета, безопасности, смены пароля, поддержки, пустого магазина и бонусов на тестовой схеме.
- Вход администратора и страницы настроек, loginserver/gameserver, новостей и статических страниц.
- Отклонение POST без CSRF, неверного пароля, чужого/неверного токена скачивания; перенаправление гостя из кабинета.
- Запрос восстановления пароля: создание токена в БД и письмо на локальный SMTP-приёмник. Завершение восстановления на реальном почтовом сервисе не проверялось.
- Визуальная проверка главной и формы регистрации; исправлено подключение jQuery.

Не проверены: реальный игровой клиент, все платные игровые услуги, живые платежи, нагрузка, конфигурация вашего хостинга. Для запуска с реальными игроками завершите пункты подключения и настройки выше.
