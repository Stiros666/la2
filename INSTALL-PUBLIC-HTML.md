# Установка через браузер — без SSH и команд

## Если сайт уже загружен и показывает 403 с просьбой выполнить prepare.php

1. Загрузите `LA2PLUS-install-update.zip` в папку `public_html` через файловый менеджер хостинга.
2. Распакуйте архив **с заменой существующих файлов**. Настройки БД, изображения и содержимое сайта этот архив не содержит и не заменяет.
3. Откройте `https://ВАШ-ДОМЕН/install/` — без `?key=...`.
4. Пройдите установку: проверка папок → данные базы сайта → создание таблиц → создание администратора.

Запускать `prepare.php`, искать `setup-url.txt` и вводить команды больше не требуется. Старый ключ, если он был создан, не нужен.

## Новая установка

Распакуйте `LA2PLUS-public_html-browser-install.zip` непосредственно в `public_html`, вместе со всеми `.htaccess`. Файл `index.php` должен находиться прямо в `public_html`. Затем откройте домен: до завершения установки он сам направит на `/install/`.

Нужны PHP 8.3 и отдельная пустая база MySQL/MariaDB для сайта. Базу и её пользователя создайте в панели хостинга. Введите их данные в форму установщика. Игровая база Lucera подключается позже в админке.

После создания администратора установка завершается автоматически и создаётся `cms-private/protected/config/lock`. Повторный запуск закрывается. Вход в админку: `/backend/`. Каталог предметов импортируется автоматически.

До завершения установки её первая страница доступна по публичному адресу. Завершите установку сразу после загрузки файлов.

## Защита файлов

Служебные файлы находятся в `cms-private`. Защита этой папки не отключена. URL `/cms-private/deny-check.txt` должен возвращать 403 или 404; это не та ошибка 403, которую раньше выдавал установщик.

Правила для Apache 2.4 включены в `.htaccess`. Для LiteSpeed нужна совместимая обработка этих правил. Для Nginx или Nginx перед Apache поддержка хостинга должна подключить запрет доступа к `/cms-private/` и конфигурацию из `cms-private/deploy/nginx.conf.example`. Сообщение 503 о правилах защиты относится к настройке веб-сервера, а не к активации установщика.

Функциональные настройки Lucera, SMTP и магазина описаны в `cms-private/INSTALL-RU.md`. Его старые указания о секретной ссылке и `prepare.php` для этого варианта больше не применяются.

## Проверено

На локальном PHP 8.3 и чистой MariaDB пройдена вся установка через HTTP без ключа: данные БД, миграции, создание администратора, автоматическая блокировка установщика, открытие главной. Проверено отклонение POST без CSRF и запрет перехода к созданию администратора из другой сессии без ввода данных БД. Конфигурацию реального хостинга нужно проверить при размещении.
